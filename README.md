# sonar
Ping with sound

Questo piccolo script in bash è stato pensato per sorvegliare un server che si spegne senza apparente motivo e avvisare dando un segnale audio,  chiesto a due AI: tgpt provider sky e duck.ai

Ho aggiunto uno script .bat per Windows, ma la risposta al ping deve essere abilitata, se no niente risposta.

This small bash script was designed to monitor a server that shuts down for no apparent reason and warn by giving an audio signal, requested by two AI: tgpt provider sky and duck.ai

I added a .bat script for Windows, but ping response must be enabled, otherwise no response.
