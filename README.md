# sonar
Ping with sound

Questo piccolo script in bash è stato pensato per sorvegliare un server che si spegne senza apparente motivo e avvisare dando un segnale audio,  chiesto a due ai tgpt provider sky e duck.ai

This small bash script was designed to monitor a server that shuts down for no apparent reason and warn by giving an audio signal, requested by two tgpt providers sky and duck.ai
